What is Intelligent Traffic Management System (ITMS)?

• An Al-powered smart traffic control system that uses YOLOv8 and computer vision to detect vehicles, measure traffic density, and give priority to emergency vehicles.

• It automates signal switching, minimizes congestion, and provides real-time monitoring through an interactive Flask dashboard.

Why Did We Build This?

Existing traffic systems rely on: Fixed timer signals & Manual control by traffic officers a No automated vehicle detection

Approach: Capture live lane video → Detect vehicles → Compute density → Dynamically manage green light timing.
